# Outputs & Evaluation Visualizations

This directory contains experimental artifacts, performance figures, and evaluation tables generated by the pipeline:

- `1_consumption_time_series.png`: Historical electricity consumption trend and seasonality.
- `2_training_validation_loss.png`: LSTM training vs. validation loss curve across epochs.
- `3_actual_vs_predicted_test.png`: Overlay of actual vs predicted electricity consumption for all models on held-out test data.
- `4_residual_distribution.png`: Histogram and KDE of forecasting residual errors (Actual - Predicted).
- `5_model_comparison_metrics.png`: Grouped bar chart comparing MAE, RMSE, and MAPE across models.
- `metrics_summary.json` / `metrics_summary.csv`: Exact calculated evaluation metrics for Persistence, Random Forest, and LSTM.
